# Basic Calculator App

A simple, modern calculator web application built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition (+), subtraction (-), multiplication (*), division (/)
- Clean and intuitive user interface
- Responsive design
- Clear (C) and Delete (DEL) functions
- Decimal number support
- Division by zero protection

## How to Use

1. Open `index.html` in your web browser
2. Click the number buttons to input numbers
3. Click an operator button (+, -, *, /) to perform operations
4. Click the equals (=) button to see the result
5. Use C to clear everything or DEL to delete the last digit

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and layout
- `calculator.js` - Calculator logic and functionality
